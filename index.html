A monorepo of vanilla web components — web standards only, no frameworks, no libraries. Components communicate through events, attributes, and slots.

Auction tools

ebidlocal-watchlist

Renders ebidlocal auction scans as a feed. Point <ebidlocal-watchlist> at a JSON feed and each auction becomes an entry with its lots as cards — new scrapes become new entries, like RSS.

Elements: ebidlocal-watchlist, watchlist-feed, auction-entry, lot-card, filter-bar · docs

Primitives

shared/component-base.js

WebComponent base class: event scoping via event-source attribute → parent element → document.body, tracked listeners with automatic cleanup, and bubbling/composed emit(). Not a rendered component — the foundation the others build on.
