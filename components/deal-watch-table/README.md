# `<deal-watch-table>`

Sortable, filterable results table for the deal-watch scans (kids electric
scooter, adult electric scooter, 24V ride-on car). The scans already produce
JSON (`baseline.json` + `last-check.json`); `tools/export-deal-feed.py` merges
those into the feed this component renders.

## Usage

```html
<deal-watch-table src="./feeds/kids-scooter.json"></deal-watch-table>
```

`src` accepts plain `.json` or `.json.gz` (gzip is detected by magic bytes,
since GH Pages doesn't send Content-Encoding). Changing `src` reloads the
feed. A page can also push data directly by dispatching `dealwatch:data`
with `{ feed }` on the component's event source (its parent by default).

See `demo.html` for the full app with a hunt picker.

## Features

- Click any column header to sort (toggles ascending/descending).
- Text filter across name, brand, retailer, and specs.
- Retailer filter chips, plus a "deals only" toggle (price below baseline).
- Price column shows the retailer's struck-through "was" price when present.
- "vs baseline" is green when the current price is below the reference price.
- Stock status, retailer badges (sale, clearance, coupon…), and one column
  per entry in the feed's `spec_columns` list.
- Missing values render as "—"; rows render without a thumbnail when the
  feed has no image URL.

## Feed schema

Documented in `feed-schema.md`. Generated by:

```
tools/export-deal-feed.py --hunt kids-scooter \
  --baseline ~/workspace/kids-scooter-hunt/kids-scooter-baseline.json \
  --last-check ~/workspace/kids-scooter-hunt/last-check.json \
  --out components/deal-watch-table/feeds/kids-scooter.json
```

## Images

Thumbnails are **hotlinked** from the retailer's own image URLs — nothing is
downloaded or cached. The price checker captures each product's main image
URL during its normal page visit (no extra requests) and the feed exporter
persists new URLs back into the baseline. Thumbnails render at 56px; click
one (or the 🔍 badge on hover) to open a full-size lightbox, click or Esc to
close. Rows without an image URL render without a thumbnail.

## Theming

Style via CSS custom properties on the element:

```
deal-watch-table {
  --dealwatch-accent: #1a73e8;
  --dealwatch-good: #1b5e20;
  --dealwatch-bad: #b3261e;
  --dealwatch-border: #e0e0e0;
  --dealwatch-muted: #666;
}
```

Slots: `header` (above the toolbar), `footer` (below the table).

## Events

- `dealwatch:data` — `{ feed }`, emitted after a successful load.
- `dealwatch:error` — `{ error }`, emitted when the feed can't be loaded.

Both bubble and are composed, per the repo's `WebComponent` conventions.
